License: GPLv2 or later

Publish approved SEO title and meta description fixes from SEO Agent, with one-click rollback.

== Description ==
SEO Agent finds pages with missing, duplicate or weak titles and meta descriptions and writes better ones. This plugin lets you publish the ones you approve straight to WordPress.

* Works with Yoast SEO, Rank Math and SEOPress (writes to their fields), or on its own.
* Every request needs an administrator Application Password and a signed connection key.
* Before writing, it checks the value hasn't changed since SEO Agent read it, so your own edits are never overwritten.
* Every change can be rolled back from SEO Agent.

== Installation ==
1. Upload the plugin and activate it.
2. Go to Settings → SEO Agent and copy the connection key.
3. Create an Application Password under Users → Profile.
4. In SEO Agent, open your site and choose Connect WordPress.
